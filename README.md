# Megalith Notes Web App

A responsive notes web application built using HTML, CSS, JavaScript and Bootstrap with account-based local storage authentication.

## Features

* Responsive UI for Desktop, Tablet and Mobile
* User Registration and Login System
* Email or Phone based Authentication
* Duplicate Account Prevention
* Login and Register using Local Storage
* User-Specific Notes Storage
* Add, Edit, Delete, full-screen and Search Notes
* Glassmorphism Dark Theme Design
* Expandable Notes Editor
* Live Search Functionality
* Logout System

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
* Local Storage API
* Font Awesome

## Project Structure

* `login.html` → Authentication page
* `notes.html` → Main notes dashboard
* `auth.js` → Login & registration logic
* `notes.js` → Notes functionality
* `style_login.css` → Login page styling
* `style_notes.css` → Notes page styling

## How It Works

### Authentication

Users can create accounts using an email or phone number and password. Duplicate accounts are prevented using Local Storage validation.

### Notes System

Each logged-in user has separate note storage using dynamically generated Local Storage keys.

### Notes Features

* Create notes
* Edit notes
* Delete notes
* Search notes instantly
* Expand notes inside modal view
