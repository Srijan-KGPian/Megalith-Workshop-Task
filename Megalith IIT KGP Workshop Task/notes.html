About Megalith Notes

Megalith Notes is a responsive notes web application built using HTML, CSS, Bootstrap, and JavaScript.

Features
  • User Login & Registration
  • User-specific Notes Storage
  • Add / Edit / Delete / Maximise Notes
  • Live Search Functionality
  • Responsive Design
Built With

HTML5, CSS3, JavaScript, Bootstrap 5, Local Storage API, Font Awesome
